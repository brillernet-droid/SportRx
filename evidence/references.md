# References

These references inform SportRx rule boundaries. SportRx does not copy any
single guideline wholesale; it translates a small subset into explicit software
rules.

For the working evidence knowledge base, see:

- `evidence/knowledge_base.md`
- `evidence/literature_matrix.md`
- `evidence/rule_evidence_map.md`
