# Evidence Questions

These are the questions SportRx must answer before becoming a stronger
evidence-informed product.

## Product-Level Questions

1. Can recreational users complete SportRx Hybrid Benchmark v1 without a coach?
2. Which benchmark components are most often missing because of equipment?
3. Does the low-equipment path produce usable repeatable data?
4. Do users understand that `Not tested` is not a bad score?
5. Does the Safety Gate language prevent users from interpreting SportRx as
   medical clearance?

## Measurement Questions

1. What is the test-retest variability of the 1 km run in SportRx users?
2. What is the test-retest variability of the Station circuit?
3. Is RowErg/SkiErg availability high enough to justify standard path first?
4. Does RPE help explain unusually poor or unusually good test results?
5. Are two measured dimensions enough to route a useful Starter Path?

## Training Questions

1. Does gap-based Starter Path routing improve adherence compared with a generic
   plan?
2. Do users with a station gap complete station practice safely and consistently?
3. Do users with a running gap improve repeatable running volume over 4 weeks?
4. Does weekly RPE prevent over-progression?

## Evidence Review Questions

1. Is there enough HYROX-specific peer-reviewed evidence to move any rules from
   `expert-informed` to stronger status?
2. Are there validated field tests that map better to HYROX-style participation?
3. Are there Chinese-language guidelines or consensus documents SportRx should
   include for Chinese users?
4. What evidence is needed before showing any aggregate score?

## Current Answer

SportRx should proceed as:

1. evidence-informed prototype,
2. measurement-first workflow,
3. conservative starter-path routing,
4. internal dataset collection,
5. validation before prediction.
