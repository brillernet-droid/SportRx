# SportRx Evidence Library

This folder is the source library for SportRx.

It stores citation records, source links, evidence tiers, and product use notes.
It does not store paywalled full text or copied article content.

## Folder Contents

| File | Purpose |
| --- | --- |
| `source_index.md` | Master source index |
| `guidelines.md` | Physical activity and exercise prescription guidelines |
| `safety_screening.md` | Preparticipation screening and safety boundary sources |
| `measurement_and_rpe.md` | Field testing, RPE, session-RPE, and monitoring sources |
| `hyrox_hift_hybrid.md` | HYROX, HIFT, hybrid competition, and concurrent training sources |
| `sources.bib` | BibTeX-style citation draft |

## Use Rule

Before a source affects a product rule, it should be linked to:

- an evidence ID in `literature_matrix.md`,
- a rule ID in `rule_evidence_map.md`,
- and, when important, a source note in `source_notes/`.

## Storage Boundary

Store:

- citation metadata,
- DOI / PMID / URL,
- evidence tier,
- SportRx use,
- limitations.

Do not store:

- paywalled PDFs,
- copied full article text,
- unlicensed datasets,
- or source material that cannot be redistributed.
