# Training Anatomy 覆盖表

| 区域 | 已记录结构 | 主要动作关系 |
|---|---|---|
| 胸部 | 胸大肌 | 肩水平内收、内收、内旋 |
| 背部 | 背阔肌、斜方肌、菱形肌群、前锯肌 | 肩伸、肩内收、肩胛上提 / 后缩 / 前伸 / 旋转 |
| 肩部 | 三角肌前中后束、肩袖肌群 | 肩屈、外展、水平外展、旋转与稳定 |
| 上臂 | 肱二头肌、肱肌、肱桡肌、肱三头肌 | 肘屈、前臂旋后、肘伸 |
| 前臂 | 腕指屈肌群、腕指伸肌群 | 腕屈、腕伸、手指动作与握持 |
| 腹壁 | 腹直肌、腹内外斜肌、腹横肌 | 屈曲、旋转、侧屈、腹腔压缩与稳定 |
| 后侧躯干 | 竖脊肌群、腰方肌 | 脊柱伸展、侧屈与稳定 |
| 股四头肌 | 股直肌、股外侧肌、股内侧肌、股中间肌 | 膝伸；股直肌同时参与髋屈 |
| 腘绳肌 | 股二头肌、半腱肌、半膜肌 | 髋伸与屈膝 |
| 臀部 | 臀大肌、臀中肌、臀小肌 | 髋伸、外展、旋转与骨盆控制 |
| 大腿内侧 | 髋内收肌群 | 髋内收及位置相关的髋屈 / 伸协同 |
| 小腿 | 腓肠肌、比目鱼肌 | 跖屈；腓肠肌还跨越膝关节 |

没有纳入颈部、手内在肌、足内在肌、呼吸肌和全部深层脊柱肌的逐条记录。它们需要
在确实影响 SportRX 产品解释或动作覆盖时，再经过独立来源审核后加入。
