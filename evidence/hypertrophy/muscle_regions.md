# 肌群区域与覆盖关系

| 肌群区域 | 主要动作家族 | 互补关系 | 当前边界 |
|---|---|---|---|
| 胸肌 | 水平推、夹胸 / 飞鸟 | 复合覆盖 + 直接肩水平内收 | 不承诺角度对应的区域增肌比例 |
| 背阔肌 | 垂直拉、水平拉 | 肩内收 / 伸展 + 划船覆盖 | 握法不直接生成“宽度”结论 |
| 上背 | 水平拉、后肩水平外展 | 肩胛后缩 + 水平外展 | 不诊断肩胛运动异常 |
| 斜方肌 | 肩胛上提、水平拉 | 上提 + 后缩任务 | 不把耸肩当作完整斜方肌覆盖 |
| 三角肌前束 | 垂直推、水平推 | 直接推举 + 协同推 | 不重复等量计算所有推类组数 |
| 三角肌中束 | 侧平举、垂直推 | 直接外展 + 复合协同 | 不建立器械效果排名 |
| 三角肌后束 | 后肩水平外展、水平拉 | 直接后肩 + 划船协同 | 不用 target 标签证明隔离 |
| 肘屈肌群 | 肘屈、垂直拉、水平拉 | 直接弯举 + 拉类协同 | 孤立动作不是固定必需项 |
| 肱三头肌 | 肘伸、水平推、垂直推 | 直接臂屈伸 + 推类协同 | 不承诺不同动作对应各头比例 |
| 股四头肌 | 膝主导、单腿膝主导、膝伸 | 复合 + 直接膝伸 | 不替个人规定深度或站距 |
| 腘绳肌 | 髋铰链、屈膝 | 跨髋与跨膝任务互补 | 不用单个硬拉动作代表完整覆盖 |
| 臀肌 | 髋伸、髋铰链、蹲类、髋外展 | 多个动作家族共同覆盖 | 不建立“最佳练臀动作” |
| 髋内收 / 外展肌群 | 内收、外展、蹲与单腿协同 | 相反方向分别记录 | 不是髋稳定性临床评价 |
| 小腿后侧 | 跖屈 / 提踵 | 直膝与屈膝设置 | 不宣称完全隔离腓肠肌或比目鱼肌 |
| 躯干 | 屈曲、抗伸展、抗旋转、抗侧屈 | 主动运动 + 稳定任务 | 不用于腰背康复和局部减脂 |
| 前臂与握力相关肌群 | 腕屈、腕伸、握持 | 直接腕动作 + 复合握持 | 握力成绩不等于前臂肌肥大 |

完整字段、英文术语、关节动作、代表动作 ID 和证据 Claim ID 见
`data/exercises/hypertrophy_atlas.json`。
