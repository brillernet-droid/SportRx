# 动作模式分类

## 为什么不只用“胸、背、腿”

一个肌群标签无法说明动作怎样完成。例如“背部训练”至少包含垂直拉、水平拉和
肩胛上提；“腘绳肌训练”至少要区分髋铰链与屈膝。SportRX 因此使用三层结构：

```text
肌群区域 → 动作模式 → 具体器械变式
```

动作模式用于发现和检查覆盖，具体变式用于执行和记录。更换器械、支撑方式或明显
不同的动作幅度后，应视为新的训练条件，不能把负重数字直接横向比较。

## 上肢主要模式

| 模式 | 主要覆盖 | 常见协同覆盖 |
|---|---|---|
| 水平推 | 胸肌 | 三角肌前束、肱三头肌 |
| 夹胸 / 飞鸟 | 胸肌 | 三角肌前束 |
| 垂直推 | 三角肌前束、中束 | 肱三头肌 |
| 侧平举 | 三角肌中束 | - |
| 后肩水平外展 | 三角肌后束 | 上背 |
| 垂直拉 | 背阔肌 | 肘屈肌、上背 |
| 水平拉 | 上背、背阔肌 | 后束、肘屈肌、斜方肌 |
| 肘屈 / 肘伸 | 肘屈肌 / 肱三头肌 | 依变式而异 |

## 下肢与躯干主要模式

| 模式 | 主要覆盖 | 不能被简化为什么 |
|---|---|---|
| 深蹲 / 膝主导 | 股四头肌、臀肌 | 与腿屈伸相同的单关节任务 |
| 单腿膝主导 | 股四头肌、臀肌 | 自动纠正左右不对称 |
| 髋铰链 | 腘绳肌、臀肌 | 腘绳肌完整覆盖 |
| 屈膝 | 腘绳肌 | 与硬拉类完全等价 |
| 髋伸 / 臀桥 | 臀肌 | 唯一或最佳练臀动作 |
| 髋外展 / 内收 | 外展与内收肌群 | 髋部筛查或康复训练 |
| 跖屈 / 提踵 | 小腿后侧 | 单一膝位完全隔离某块肌肉 |
| 躯干屈曲 | 腹壁 | 局部减脂动作 |
| 稳定任务 | 躯干控制 | 腰痛诊断或康复建议 |

## 分类不是剂量

图谱不会把一个复合动作的一组自动拆成多个肌群的等量“有效组”。当前证据不足以
支持一个适用于所有动作、技术与训练者的固定折算系数。肌群周组数仍属于独立的
处方规则问题。
