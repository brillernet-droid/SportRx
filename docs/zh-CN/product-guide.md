# 产品说明

SportRX v0.1 的中心不是聊天窗口、体能评分或赛事预测，而是「处方引擎 + 动作内容库」：
处方引擎从用户当下能够做到的训练量开始，用完成率和 RPE 决定是否调整；动作库提供
全训练场景可复用的动作、器械与操作说明。

[返回项目主页](../../README.md) · [首次体验](quickstart.md) · [产品边界](claim-boundaries.md)

## 核心闭环

```text
设置
  ↓
基础筛查与当前活动状态
  ↓
4 周 FITT-VP 有氧计划
  ↓
今天训练
  ↓
完成率 + RPE
  ↓
维持 / 小幅进阶 / 降低 / 暂停
```

## 四个页面

| 页面 | 用户要做什么 | 系统做什么 |
| --- | --- | --- |
| 首页 | 执行今天的训练。 | 直接展示动作、时长、RPE 和关键提醒。 |
| 处方 | 填写近期活动、时间和偏好。 | 用两步完成初始状态、可用容量和安全边界。 |
| 记录 | 记录完成次数和平均 RPE。 | 重新计算接下来的训练，并展示为什么维持、进阶、降低或暂停。 |
| 动作 | 搜索动作、部位或器械。 | 提供动作内容与中文操作步骤，不自行开训练量。 |

## 规则层

规则引擎决定：

- 当前运动状态：目前运动不足、已有一些运动基础、已较规律运动；
- 第 1 周的频率与时长：同时受近期活动量和现实时间约束；
- 强度：用 RPE 与说话测试提供无设备也可执行的方式，可选目标心率；
- 进阶：用完成率、平均 RPE、偏难和异常反馈决定下一周。

模型或 RAG 不决定上述剂量。未来的知识库只可解释已有规则和研究证据，不能改变
当前用户的安全状态、训练量或进阶结果。

## 当前范围

v0.1 的自动处方只支持表观健康、18–64 岁成人的有氧训练起点。目标固定为改善
有氧体适能与一般健康；不做减脂算法、营养、可穿戴设备、聊天教练或赛事计划。

动作库已经覆盖力量、核心、心肺和功能性动作内容，但这不代表力量或专项计划已经
自动开放。每一种新处方模块都需要独立的输入定义、剂量规则、证据映射、停止边界和
回归测试，才可以从“动作可浏览”升级为“计划可自动生成”。

训练不是一次性写死：先实际执行一周，再根据反馈决定下一周。这个闭环跑顺以后，
才值得考虑引入更复杂的表现测量或机构场景。
