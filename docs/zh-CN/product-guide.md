# 产品说明

SportRX 的中心不是聊天窗口、体能评分或赛事预测，而是「处方内核 + Program Pack +
动作内容库」：处方内核从用户当下能够做到的训练量开始，用完成率和 RPE 决定是否调整；
Program Pack 规定哪一类场景能使用哪些规则；动作库提供全训练场景可复用的动作、器械
与操作说明。

## 核心闭环

```text
当前场景 + 目标
  ↓
Program Pack 路由
  ↓
基础筛查与当前活动状态
  ↓
当前周 FITT-VP 有氧处方
  ↓
今天训练
  ↓
每次完成情况 + RPE
  ↓
维持 / 小幅进阶 / 降低 / 暂停
```

## 五个页面

| 页面 | 用户要做什么 | 系统做什么 |
| --- | --- | --- |
| 今天 | 执行今天的训练。 | 直接展示动作、时长、RPE 和关键提醒。 |
| 我的计划 | 查看当前周与适应性路线。 | 仅承诺当前周；把未来周标记为等待反馈。 |
| 评估 | 填写目标、近期活动、时间和偏好。 | 匹配 Pack，再完成初始状态、可用容量和安全边界。 |
| 进展 | 每次记录是否完成、本次 RPE 和异常情况。 | 自动汇总本周，重新计算接下来的训练，并展示为什么维持、进阶、降低或暂停。 |
| 我的资料 | 查看当前 Pack 与数据使用情况。 | 显示适用路径、当前边界和尚未测量的字段；可进入动作内容库。 |

## 规则层

规则引擎决定：

- 当前运动状态：目前运动不足、已有一些运动基础、已较规律运动；
- 第 1 周的频率与时长：同时受近期活动量和现实时间约束；
- 强度：用 RPE 与说话测试提供无设备也可执行的方式，可选目标心率；
- 进阶：用本周单次记录汇总出的完成率、平均 RPE、偏难和异常反馈决定下一周。

模型或 RAG 不决定上述剂量。未来的知识库只可解释已有规则和研究证据，不能改变
当前用户的安全状态、训练量或进阶结果。

## 当前范围

当前已发布的自动处方支持表观健康、18–64 岁成人的有氧训练起点。低活动有氧 Pack
与一般体能建立 Pack 的自动化均限于有氧；代谢健康关注与表现目标入门当前只进入评估
路径。完整状态见 [Program Pack 路径](program-packs.md)。

动作库已经覆盖力量、核心、心肺和功能性动作内容，但这不代表力量或专项计划已经
自动开放。每一种新处方模块都需要独立的输入定义、剂量规则、证据映射、停止边界和
回归测试，才可以从“动作可浏览”升级为“计划可自动生成”。

训练不是一次性写死：先实际执行当前周的每一节，再根据反馈决定下一周。这个闭环跑顺以后，
才值得考虑引入更复杂的表现测量或机构场景。
