# 术语说明

SportRX v0.1 的用户界面使用中文，只保留少量运动科学中更容易识别的英文术语。

[返回项目主页](../../README.md) · [产品说明](product-guide.md) · [完整受控术语表](../../evidence/glossary.md)

| 术语 | 中文说明 | 当前边界 |
| --- | --- | --- |
| SportRX | 产品品牌。 | Python 包名仍为 `sportrx`。 |
| FITT-VP | 频率、强度、时间、类型、总量与进阶。 | 是 v0.1 计划的结构，不是医疗处方。 |
| RPE | 主观用力程度，使用 0–10 记录训练体感。 | 不是客观生理指标、恢复评分或医学指标。 |
| 说话测试 | 用能否舒适说话来辅助判断强度。 | 无设备时可与 RPE 一起使用。 |
| 完成率 | 实际完成训练次数除以计划次数。 | 只用于下一周规则调整，不代表意志力或健康评分。 |
| 暂停自动调整 | 出现异常不适或不良事件后停止系统进阶。 | 不判断原因，也不提供继续训练建议。 |

测量实验室、赛事、设备和场馆流程仍保留在仓库的研究材料中，但不是 v0.1 的默认
用户体验。中文说明不替代原始来源、规则 ID 或数据 schema。
