# 首次体验与本地运行

SportRX 当前默认运行的是训练处方 v0.1：有氧模块可自动生成 4 周计划，动作库提供
多种训练动作的内容与中文操作说明。它用于自用和小样本体验，不是医疗服务，也不是
已验证的训练效果系统。

[返回项目主页](../../README.md) · [产品说明](product-guide.md) · [产品边界](claim-boundaries.md)

## 运行环境

需要 Python 3 和本项目声明的依赖。进入项目根目录后运行：

```bash
python3 -m pip install -e ".[dev,app]"
python3 scripts/smoke_check.py
bash scripts/run_local.sh
```

浏览器打开终端输出的本地地址。默认使用 `127.0.0.1:8501`；如端口被占用，可使用
`SPORTRX_PORT=8502 bash scripts/run_local.sh`。

## 3 分钟体验

首次打开就是中文、手机优先的五步流程：

1. **设置**：填写年龄、最近 4 周运动天数与分钟数、未来可训练天数、单次时间和偏好方式。
2. **计划**：查看 4 周 FITT-VP 有氧计划。每周都展示频率、强度、时间、类型、总量与进阶状态。
3. **今天**：查看第一节训练的活动、时长、RPE、说话测试和结束后的记录动作。
4. **进度**：在周末填写完成次数、平均 RPE、是否偏难和是否出现异常；下一周随即按规则更新。
5. **动作库**：按部位、器械或关键词查找动作，查看中文操作步骤。

第 2–4 周是会随反馈变化的预览，不是第一天就写死的完整处方。

## 输入与输出

v0.1 只收集会改变输出的字段：

- 年龄：限定当前适用范围为 18–64 岁；
- 最近 4 周的运动天数与中高强度分钟数：决定初始运动状态与第 1 周总量；
- 未来可训练天数与单次时间：限制频率和时长；
- 偏好方式：决定快走、轻松慢跑、骑行或椭圆机等训练类型；
- 可选静息心率：知道时才用来补充目标心率；
- 最小开始前确认：出现警示情况、相关疾病或不确定时，停止自动处方。

系统输出每周训练次数、每次时长、周总量、RPE、说话测试和具体训练日。

动作库当前收录 1,324 个文字动作条目，来源、许可和更新方式见
[动作内容库说明](../../data/exercises/README.md)。动作条目不自行产生组数、次数、
强度或进阶；这些必须由相应训练模块的规则决定。

## 周反馈

每周用四个字段更新下一周：

- 完成率高且 RPE 低：可增加训练量；
- 完成率高且 RPE 适宜：小幅进阶；
- 完成率低且偏难或 RPE 高：降低训练量；
- 出现异常不适或不良事件：暂停自动调整。

这是规则解释，不是医疗建议或恢复评分。更多边界见 [产品边界](claim-boundaries.md)。
