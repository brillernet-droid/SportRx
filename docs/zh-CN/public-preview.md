# SportRX v0.1 公开预览

当前公开预览展示 SportRX 最初的有氧运动处方闭环：

```text
基础信息 → 4 周 FITT-VP 计划 → 今天训练 → 完成率 / RPE → 下一周调整
```

## 当前能做什么

- 用最近 4 周的运动情况和可用时间生成一份 4 周有氧训练起点；
- 查看每次训练的方式、时长、RPE 和说话测试；
- 在周末记录完成次数、平均 RPE、是否偏难，并查看规则如何调整下一周。

## 使用边界

- 这是原型，不提供医疗许可、诊断、伤病风险、赛事预测或营养建议；
- 仅面向 18-64 岁、表观健康成年人；
- 出现警示症状、相关疾病或不确定情况时，系统不会自动生成或调整计划；
- 当前部署不设用户账户或持久化数据库。不要输入姓名、联系方式或可识别的健康细节；
- 公网试用、数据保留、删除机制与独立验证完成前，不构成真实场馆服务。
