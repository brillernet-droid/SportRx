# SportRX 公开示例站

SportRX 的公网版本目前是**合成数据示例站**，用于展示以下产品闭环：

```text
Benchmark 流程 → Training Profile → Starter Path → RPE / Completion → Retest
```

## 当前能做什么

- 浏览基于合成案例的 Benchmark、训练画像、训练与复测页面；
- 了解哪些数据是实测、哪些是 `Not tested`；
- 查看规则驱动的解释和明确的产品边界。

## 当前不能做什么

- 不接收真实会员入会筛查；
- 不接收姓名、联系方式、健康信息或真实表现数据；
- 不提供医疗许可、诊断、伤病风险、赛事预测或真实训练服务；
- 不构成场馆试点或用户数据采集。

请不要在示例站输入任何个人或健康数据。真实场馆版本仍需完成中国本地筛查路径、
隐私告知、同意、保留与删除机制、人员升级流程，以及独立试用验证后才可考虑。
