# SportRX 目标优先运动处方设计 v0.1

**状态：** 产品与规则设计依据。不是已经验证的自动处方声明。

## 1. 这次修正什么

SportRX 当前运行版本只具备低活动成年人有氧起步规则。它可以回答“从多少有氧
训练开始”，但不能因此自称完整的通用运动处方。

新版入口必须先回答：

```text
首要训练目标
→ 当前训练暴露与经验
→ 可用时间、场地和器械
→ 安全边界
→ 匹配独立的目标处方方案
→ 生成当前周训练组成和 FITT-VP
→ 完成情况、RPE / RIR、实际训练量
→ 下一周调整
```

目标用于选择处方方案，不能单独决定剂量。相同的“增肌”目标，对从未抗阻训练的
人和已经稳定训练三年的人，不应产生同一份计划。

## 2. 为什么不能只输出有氧计划

ACSM 面向表观健康成年人的处方立场指出，常规计划应考虑心肺、抗阻、灵活性和
神经运动训练，而不是只覆盖一种运动类型。WHO 的成人指南也同时包括有氧活动和
肌力强化方向。

- [ACSM 成人综合运动处方立场文件，PMID 21694556](https://pubmed.ncbi.nlm.nih.gov/21694556/)
- [WHO 身体活动和久坐行为指南](https://www.who.int/publications/i/item/9789240014886)

因此，SportRX 的基本输出单位应从“每周有氧分钟数”升级为“目标相关的周训练
结构”。每个训练类型仍使用自己的 FITT-VP 或等价剂量字段。

## 3. 首批目标处方方案

| 目标 | 主要训练组成 | 处方必须管理的剂量 | 当前状态 |
| --- | --- | --- | --- |
| 建立运动习惯 | 低门槛有氧为主 | 天数、分钟、RPE、完成率 | 已运行 |
| 提升心肺适能 | 有氧为主，抗阻为健康底座 | 频率、强度、时间、方式、周量、进阶 | 已运行基础版 |
| 改善综合体能 | 心肺、抗阻、灵活性、协调 | 各类型周频率、单次内容、恢复与总时间 | 待建立组合规则 |
| 增加肌肉量 | 抗阻为主，保留基础心肺 | 肌群周组数、负荷、次数、RIR / RPE、休息、频率 | 仅识别目标 |
| 减少脂肪并改善体成分 | 有氧与抗阻组合 | 有氧周量、抗阻剂量、完成率与可持续性 | 仅识别目标 |
| 专项表现 | 专项测量后生成项目方案 | 专项训练量、强度分布、测试和复测 | 测量优先 |

## 4. 不同目标为什么使用不同旋钮

### 增肌

2026 年 ACSM 抗阻训练立场文件汇总 137 篇系统综述和超过 30,000 名参与者的
证据。其结论强调：规律抗阻训练本身最重要；增肌可通过较高周训练量进一步优化，
而力量更受高负荷影响。公开摘要给出的增肌方向约为每个肌群每周 10 组或以上，
但这不能直接变成每名初学者第一周的固定起点。

- [ACSM 2026 抗阻训练处方立场文件，PMID 41843416](https://pubmed.ncbi.nlm.nih.gov/41843416/)
- [ACSM 2026 官方要点](https://acsm.org/resistance-training-guidelines-update-2026/)
- [抗阻处方网络 Meta 分析，PMID 37414459](https://pubmed.ncbi.nlm.nih.gov/37414459/)

SportRX 因而必须先知道：近期抗阻训练频率、训练经验、可用器械、每周可练天数、
单次时间、希望重点发展的部位，以及当前动作是否能够稳定完成。处方输出必须按
肌群核算周组数，并记录实际组数、次数、负荷和 RIR 或 RPE。

“练到完全力竭”不能成为默认规则。现有综述没有显示完全力竭对所有人和所有结果
都更优，用户对 RIR 的估计也可能不准确。

- [接近力竭与增肌综述，PMID 36334240](https://pubmed.ncbi.nlm.nih.gov/36334240/)
- [RIR 剂量反应 Meta 回归，PMID 38970765](https://pubmed.ncbi.nlm.nih.gov/38970765/)

### 减脂与体成分改善

运动对体重和体成分有帮助，但平均体重变化通常有限，不能把运动处方包装成确定的
减重承诺。较新的有氧训练剂量反应 Meta 分析显示，有氧周量增加与体重、腰围和
体脂改善相关；欧洲肥胖研究协会的证据综述同时建议使用抗阻训练帮助维持瘦体重。

- [有氧运动与减重剂量反应 Meta 分析，PMID 39724371](https://pubmed.ncbi.nlm.nih.gov/39724371/)
- [EASO 成人超重与肥胖运动建议，PMID 34076949](https://pubmed.ncbi.nlm.nih.gov/34076949/)

因此该方案应输出“有氧加抗阻的组合训练”，并显示活动量、完成率和体成分测量
条件；不能输出承诺减重数字、虚构热量缺口或仅靠 BMI 生成剂量。

### 综合体能

综合体能不是把有氧、力量动作和拉伸随机拼在一起。它需要在用户可用天数中分配
心肺和抗阻训练，同时控制同日训练顺序和恢复。并行训练的更新综述显示，组合有氧
和力量训练通常不会削弱增肌或最大力量，但同一节训练可能更影响爆发力适应。

- [并行有氧与力量训练综述，PMID 34757594](https://pubmed.ncbi.nlm.nih.gov/34757594/)

## 5. 输入必须真正改变输出

### 所有目标的共同输入

1. 首要训练目标。
2. 年龄与成人适用范围。
3. 最近 4 周实际训练天数和分钟数。
4. 每周可用天数和单次最长时间。
5. 场地与器械条件。
6. 明确的安全路由结果。

### 抗阻目标的附加输入

1. 最近 4 周抗阻训练天数。
2. 连续抗阻训练经验。
3. 可用器械和可稳定完成的动作模式。
4. 当前主要动作的实际组数、次数和负荷；没有测量时保持未测试。
5. 训练重点部位和可接受的每周频率。

若某个字段不参与路由、起点、动作约束、剂量或进阶，就不应在该方案中收集。

## 6. 处方输出合同

每个目标方案至少返回：

```text
适用范围与版本
当前周目标
周训练日历
每节训练的训练类型
每种训练类型的 FITT-VP 或等价剂量
动作模式、组数、次数、负荷表达、休息
RPE / RIR 执行范围
替代动作与器械约束
停止自动化条件
完成后记录字段
下一周进阶、维持或降低规则
证据和局限
```

动作库只为已经确定的动作模式提供具体动作候选和操作说明。它不能根据动作数量
反推用户应该训练多少。

## 7. 发布顺序

1. **目标优先入口：** 第一屏独立选择目标，禁止未知目标回退到有氧计划。
2. **增肌入门方案：** 先覆盖表观健康、无康复需求的初学者，完成肌群周组数和
   实际负荷记录，再开放自动剂量。
3. **综合体能方案：** 建立有氧与全身抗阻的周结构和时间冲突处理。
4. **减脂组合方案：** 复用前两者，增加体成分测量一致性与禁止减重承诺。
5. **真实试用：** 分别观察完成率、RPE / RIR 可填写性、动作替换和周进阶，而不是
   把所有目标混成一个平均结果。

## 8. 当前不可声称

- 不能因为用户选择“增肌”就用随机力量动作填满一周。
- 不能把有氧消耗估算写成减脂结果预测。
- 不能从问卷推断 1RM、肌肉量、体脂率或动作能力。
- 不能让 AI 或动作库绕过方案规则决定训练剂量。
- 不能把尚未审核的目标方案显示成“已为你科学定制”。
