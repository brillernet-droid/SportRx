# SportRX

> **用有限时间条件，生成一份可解释、可调整的 4 周有氧运动处方。**

SportRX 是一个面向表观健康成年人、只做有氧训练的运动处方原型。它不是 AI
健身教练：规则引擎决定训练频率、强度、时间、类型、总量和周度进阶；界面只把
这些规则组织成一份能执行、能反馈的计划。

**开得稳，讲得清，能调整。**

## SportRX 解决什么问题

第一版只解决一个问题：一个表观健康、目前运动不足的成年人，在有限时间条件下，
未来 4 周应该怎样开始有氧运动？

```text
基础信息 → 基础筛查 → 当前运动状态 → 可用时间 → 4 周 FITT-VP 计划
→ 完成训练 → RPE / 完成情况 → 下一周调整
```

## 核心体验

| 价值 | SportRX 的做法 |
| --- | --- |
| 开得稳 | 从近期活动量和可用时间开始，而不是把统一目标直接压给每个人。 |
| 讲得清 | 每一周都展示 FITT-VP、RPE、说话测试和计划生成原因。 |
| 能调整 | 完成率和平均 RPE 决定维持、小幅进阶、降低训练量或暂停自动调整。 |
| 不越界 | 警示症状、相关疾病或不确定情况会阻断自动处方，不作医疗判断。 |

## 3 分钟体验

```bash
python3 -m pip install -e ".[dev,app]"
python3 scripts/smoke_check.py
bash scripts/run_local.sh
```

打开终端显示的本地地址后，按下面四步体验：

1. 在 **设置** 填写年龄、最近 4 周运动量、可训练天数、单次时间和运动偏好。
2. 在 **计划** 查看系统生成的 4 周 FITT-VP 有氧安排。
3. 在 **今天** 查看一节训练应该怎么做、多久、RPE 多高。
4. 在 **进度** 记录完成次数与平均 RPE，查看下一周如何调整。

完整说明见 [首次体验与本地运行](docs/zh-CN/quickstart.md)。

## 产品能力地图

| 阶段 | 用户能看到的能力 | 当前原则 |
| --- | --- | --- |
| 1. 设置 | 当前活动量与现实时间 | 只收集会改变处方输出的字段。 |
| 2. 4 周计划 | 频率、强度、时间、类型、总量与进阶 | 规则决定起始量，不由模型自由生成。 |
| 3. 今天训练 | 活动方式、时长、RPE、说话测试 | 让用户明确今天该做什么。 |
| 4. 周反馈 | 完成率、平均 RPE、偏难与异常 | 规则决定维持、进阶、降低或暂停。 |

机构交付、测试员操作与复测逻辑见 [产品说明](docs/zh-CN/product-guide.md)。

## 当前状态与验证计划

SportRX 目前是一个**有氧运动处方原型**，不是已完成验证的医疗、预测或赛事系统。
当前工作重点是验证一条自用闭环能否被正确使用：

1. 自用：完成 4 周计划、每周 RPE/完成记录与调整。
2. 小样本试用：观察首次设置、第一节训练与周反馈能否独立完成。
3. 再评估是否引入表现测试、场馆流程或真实复测研究。

在积累足够真实数据与正式验证之前，SportRX 不会将内部规则、原型排序或测试
流程称为人群常模、运动准备度评分、风险预测或赛事能力预测。

## 安全与产品边界

SportRX 不提供疾病诊断、医疗清除、伤病风险百分比、完赛概率、假百分位、赛事
认证、营养建议或 AI 自动处方。出现需要进一步专业评估的信息时，系统会停止自动
生成或调整训练计划。AI 也不决定安全状态、训练强度、周运动量或进阶。

完整边界见 [产品边界](docs/zh-CN/claim-boundaries.md)。

## 项目结构

```text
SportRX/
├── app/          # Streamlit 本地演示
├── sportrx/      # 规则引擎、测量记录、报告与导出
├── evidence/     # 证据库、结构化规则记录与内部审阅检索评测
├── docs/zh-CN/   # 面向中文使用者的公开说明

```

证据库、规则 ID、数据 schema 和原始文献链接继续使用英文，避免维护两套逐字
技术文件。中文页面提供产品层说明，并链接到对应的公开技术材料。

内部循证记录将来源、可支持结论、产品规则和测试协议连成可审阅链条。它只用于
规则审阅与未来的受限解释，不是用户聊天机器人，也不会改变训练剂量。测量组件的
证据状态与不可声称内容见
[Benchmark 组件证据台账](evidence/source_notes/006_benchmark_component_evidence.md)。

## 内部知识 RAG

SportRX 另有一个内部研究型 Knowledge Lab，用于检索已审核的运动科学知识卡并
在通过门槛后生成带引用和局限的中文研究摘要。它与 v0.1 的规则引擎分开：知识
RAG 不能改变安全边界、训练剂量或进阶，也不会作为公开用户聊天功能。它是未来
研究资产，不是当前默认产品体验。其公开元数据与审核规则见
[Knowledge Corpus](evidence/knowledge/README.md)。
