# Deploy SportRx on Tencent Cloud

SportRx is a Streamlit application. The public repository includes a `Dockerfile`
so it can be deployed as a container.

## Recommended Tencent Cloud Path

Use Tencent CloudBase Run / CloudBase Hosting if you want a managed container
deployment. Use Lighthouse or CVM if you want a simple virtual server.

## Option A: Tencent CloudBase Run

1. Open Tencent CloudBase / CloudBase Run in the Tencent Cloud console.
2. Create a new service from the GitHub repository:

   ```text
   https://github.com/brillernet-droid/SportRx
   ```

3. Choose Dockerfile deployment.
4. Set the service port to:

   ```text
   8501
   ```

5. Keep the runtime environment variable:

   ```text
   PORT=8501
   ```

6. Deploy the service and use the public service URL generated by Tencent Cloud.

## Option B: Tencent Lighthouse / CVM

On a clean server with Docker installed:

```bash
git clone https://github.com/brillernet-droid/SportRx.git
cd SportRx
docker build -t sportrx .
docker run -d --name sportrx -p 80:8501 -e PORT=8501 sportrx
```

Then open:

```text
http://YOUR_SERVER_PUBLIC_IP
```

Make sure the Tencent Cloud firewall/security group allows inbound HTTP traffic
on port `80`. If you map `8501:8501` instead, allow inbound traffic on `8501`.

## Local Check Before Deployment

```bash
pip install -e ".[app,dev]"
pytest -q
python scripts/smoke_check.py
python -m streamlit run app/streamlit_app.py --server.address 0.0.0.0 --server.port 8501
```

## Important Boundary

SportRx is a measurement-first sport-science prototype. Deployment makes the
prototype accessible on the web; it does not validate the exercise rules,
create medical clearance, or prove user outcomes.
